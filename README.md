# Telegram Emoji & Sticker Studio (.TGS / Lottie)

Профессиональное десктопное Windows-приложение (.EXE) для создания, редактирования и анимации кастомных эмодзи и стикеров Telegram (.TGS / Lottie) на базе автономного движка `emote-engine.js`.

---

## 🚀 Быстрый запуск и компиляция в .EXE в 3 команды

### Способ 1: Запуск в режиме разработки (Desktop GUI)
```bash
# 1. Установка зависимостей (один раз)
npm install

# 2. Мгновенный запуск редактора
npm start
```

### Способ 2: Сборка в один автономный переносимый файл `Telegram Emoji Studio.exe` (Portable .EXE)
```bash
# 1. Сборка готового автономного .exe под Windows (без установки)
npm run build
```
Готовый .EXE файл создается в папке:  
`dist/Telegram Emoji Studio-Portable-1.0.0.exe` (или в `dist/win-unpacked/Telegram Emoji Studio.exe`).

### Способ 3: Сборка установочного Setup.exe инсталлятора
```bash
# 1. Сборка Setup инсталлятора для Windows
npm run dist
```
Результат появится в папке `dist/Telegram Emoji Studio Setup 1.0.0.exe`.

## 🌟 Ключевые возможности

1. **100% Офлайн и автономность**:
   - Библиотеки `opentype.js`, `pako.js`, `lottie-web` и встроенный base64-шрифт Apple-style вшиты локально. Приложение работает без доступа к сети.
2. **Настоящие кривые Безье (rlottie standard)**:
   - Текст переводится напрямую в векторные слои `ty: 4` (Lottie Bezier Shapes) с правилом Non-Zero Winding, что гарантирует идеальную отрисовку на всех клиентах Telegram (Android, iOS, macOS, Windows Desktop).
3. **Строгая валидация лимита 64 КБ**:
   - Автоматический расчет веса сжатого .TGS в реальном времени. Зеленый индикатор в шапке при соответствии норме и предупреждение при превышении.
4. **Интерактивный 512×512 холст**:
   - Bounding Box выделения активного текста, перемещение мышкой, масштабирование колесиком мыши (зум 50% - 200%), панорамирование.
5. **Мультиформатный экспорт**:
   - `.TGS` (официальный Telegram-стикер);
   - `.GIF` 512×512 с умной палитрой quantize;
   - `.MP4` 60 FPS через захват кадров;
   - `.JSON` чистый исходник Lottie.
6. **Интерактивный Таймлайн**:
   - Покадровый скраббинг бирюзовым вертикальным бегунком (Playhead);
   - Полосы слоев с возможностью перемещения и растягивания за края (настройка In/Out points: `ip` - `op`).
7. **Модуль подписки (400 ₽ / 30 дней)**:
   - Включает класс `LicenseManager` в режиме `DEV_UNLOCKED = true` с возможностью мгновенной активации ключей и проверки срока действия.
